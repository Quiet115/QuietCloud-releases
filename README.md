# QuietCloud · descargas

QuietCloud comparte archivos entre tus propios dispositivos sin subirlos a ninguna nube. Cada equipo guarda sus archivos y los manda directo, cifrados, al que los pide.

Este repositorio solo contiene los instaladores. El código no es público.

## Descargar

En [Releases](../../releases/latest):

- **Windows 10 u 11:** `QuietCloud_<versión>_x64-setup.exe`. Se instala para tu usuario, sin permisos de administrador. Windows puede mostrar un aviso de SmartScreen porque el instalador todavía no lleva firma de código: «Más información» → «Ejecutar de todas formas».
- **Android 10 o superior:** `QuietCloud-<versión>.apk`. Android pedirá permitir la instalación desde el navegador o el gestor de archivos.

## Actualizaciones

Desde la versión 0.2.0 la app se actualiza sola: avisa al abrirse si hay una versión nueva y se instala desde **Ajustes → Acerca de → Actualizaciones**. Antes de instalar comprueba que la versión está firmada por QuietCloud; si la firma no coincide, no instala nada.

`SHA256SUMS.txt` lleva la huella de cada archivo de la versión.
